# Gym Website

## Project Overview
This is a **Gym Website**, second project of the **Foundations of Frontend Development** course. The project showcases a modern and responsive website for a gym, featuring essential sections such as home, about, services, membership plans, contact information, and a workout gallery.

## Features
- **Responsive Design** – Works across various screen sizes and devices.
- **Navigation Bar** – Includes links to different sections for easy navigation.
- **Homepage** – Engaging hero section with a call to action.
- **About Us** – Information about the gym, its mission, and vision.
- **Membership Plans** – Different subscription options for users.
- **Gallery** – A collection of images showcasing the gym and its facilities.
- **Testimonials** – User feedback and success stories.
- **FAQ Section** – Answers to common questions.
- **Contact Page** – A form for users to reach out for inquiries.
- **Dark Mode Toggle** – Users can switch between light and dark themes.
- **Group Training Page** – Dedicated section for group training programs.
- **Programs Section** – Offers details on different workout programs.
- **Nutrition & Wellness Page** – Focused on healthy lifestyle guidance.
- **Wellness Coaching** – Provides personalized coaching sessions.
- **Mindfulness & Meditation** – Supports mental health and stress reduction.
- **Member Profile Page** – Allows users to manage personal details and track fitness progress.
- **Progress Tracker** – Displays fitness achievements through progress bars.
- **Recent Activity Section** – Shows users' latest gym activities.

## Technologies Used
- **HTML5** – Structuring the website content.
- **CSS3** – Styling and layout using modern techniques.
- **JavaScript** – Adding interactivity and dynamic behavior.
- **Bootstrap** – Enhancing responsiveness and styling.
- **jQuery** – Used for form validation and UI interactions.
- **Toastr.js** – Notifications for user interactions.
- **Google Maps API** – Embedded map for location display.
